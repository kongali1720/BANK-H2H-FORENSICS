# BANK-H2H-FORENSICS Wiki Index

This file is the proposed starting structure for the GitHub Wiki.

## Wiki Home

BANK-H2H-FORENSICS is an independent financial file intelligence and transaction evidence analyzer.

The Wiki is intended to document how the project works, its methodology, supported formats, development practices, security controls, and limitations.

## Documentation Principle

Wiki pages must describe implemented behavior accurately.

Planned functionality must be labeled as planned, experimental, or not yet implemented.

A parsed file is not proof of bank authenticity, payment execution, settlement, available balance, or beneficiary credit.

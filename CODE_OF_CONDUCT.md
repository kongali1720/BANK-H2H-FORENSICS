# Code of Conduct

## Our Commitment

BANK-H2H-FORENSICS is committed to a respectful, constructive, inclusive, and professional community.

We aim to provide a space where people can collaborate on financial-file analysis, software engineering, security, research, and documentation.

## Expected Behavior

Community members are expected to:

- Be respectful and professional.
- Welcome questions from beginners.
- Provide constructive feedback.
- Focus on technical evidence.
- Respect privacy.
- Respect different experience levels.
- Acknowledge mistakes.
- Avoid personal attacks.
- Communicate clearly and honestly.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or intimidation.
- Discrimination.
- Threats.
- Personal attacks.
- Publishing private information.
- Doxxing.
- Deliberate misinformation.
- Impersonating banks, institutions, or project maintainers.
- Fabricating financial evidence.
- Using project discussions to facilitate financial fraud.
- Posting confidential banking information.
- Encouraging unauthorized access to third-party systems.

## Responsible Financial Discussions

Financial-file analysis must remain evidence-oriented.

Do not use project discussions to claim that a transaction has been executed, settled, authenticated, or credited when the available evidence does not establish those facts.

## Moderation

Project maintainers may edit, remove, close, or reject content that violates this Code of Conduct or threatens the safety, privacy, integrity, or lawful operation of the project.

## Reporting

Report conduct concerns to the project maintainers through an appropriate private channel when available.

Avoid posting sensitive information publicly.

## Enforcement

Maintainers may take appropriate action based on the severity and circumstances of an incident, including:

- Warning
- Content removal
- Temporary restrictions
- Blocking
- Removal from project participation

## Attribution

This Code of Conduct is adapted from common open-source community standards and is intended to support a respectful technical community.
